目录结构

ReinAgent/
├── src/                  # 前端（React 19 + TypeScript + Tailwind CSS v4）
│   ├── components/       # chat / trajectory / git / sidebar / settings
│   ├── lib/              # agent / chat / providers / git / stt / storage
│   ├── store/            # Zustand 全局 Store
│   └── styles/           # 语义主题变量（global.css）
├── src-tauri/src/        # Tauri 2 / Rust 后端与命令
├── docs/                 # 本官网与项目文档
└── AGENTS.md             # 工作区规则单一真相源
依据项目规范，正式发布构建 bun run tauri build 由项目本人运行，避免长时间占用构建产物与 bundle 目录。
