常见问题

启动、模型、上下文与回退排查

无法启动或窗口空白

确认系统已具备 WebView 运行时：Linux 需 webkit2gtk，Windows 需 Microsoft Edge WebView2（Win10 / 11 自带）。绿色版无需额外安装 Node.js、Python 或 Rust。

模型列表拉取失败

先检查代理配置。配置了 HTTP / SOCKS 代理后，模型列表拉取会严格走代理；若上游接口未返回上下文窗口等元数据，界面会显示为未知并提示，而不是填一个猜测值。

会话越长越慢或断连

ReinAgent 基于真实的上下文窗口计算水位线，达到 70% 自动压缩，并对历史工具结果做微压缩。若使用本地反代，报文上限已放宽至 32MB。

想撤销 Agent 的某轮改动

使用检查点回退：文件修改前由 Rust 后端留存前像，UI 支持逐轮撤销，并有 SHA-256 指纹冲突防护。

数据在哪，能否迁移

全部在 ~/.ReinAgent/ 下：配置、SQLite 库、检查点与默认工作区。整目录备份即可迁移。
