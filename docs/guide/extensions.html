Skills 与双向 MCP 生态

扩展方式角色说明
MCP 客户端（Client）ReinAgent → 外部工具连接外部 MCP Server（本地进程 / SSE），供工作台内部模型调用扩展工具
MCP 服务端（Server）外部大模型 → ReinAgent遵循 MCP 2024-11-05 协议，通过 HTTP/SSE 暴露 15 个工具，供 Claude Desktop、Cursor 等外部 AI 反向直接操控 ReinAgent
ClawHub 技能生态技能扩展支持一键安装内置/自定义技能与磁盘目录技能体系

实时语音输入（STT）

支持腾讯云、火山引擎、百度千帆、阿里 DashScope 实时语音 WebSocket 流式转写，输入框草稿无缝接续。
