审批与检查点

四档审批模式、检查点与原子回退

ReinAgent 的每一步写操作与命令执行都可审批、可回退。这是它与「只给建议」的对话式工具最本质的差别。

四档审批模式（ApprovalMode）

模式行为
plan计划模式，只读调研，拦截一切修改操作
ask变更前审批，写文件与执行命令均需确认
edit自动放行编辑，执行命令时弹窗确认
full完全访问直通

审批基于 beforeToolCall 挂起机制实现：审批触发时 Agent 运行回路安全暂停，用户决策后即时恢复，不会丢失中间状态。

代码改动检查点与原子回退

机制说明
前像留存文件被修改前由 Rust 后端自动留存前像
逐轮撤销UI 支持按轮次撤销代码改动（Checkpoint & Rewind）
冲突防护基于 SHA-256 指纹的 TOCTOU 冲突检测，避免覆盖外部改动
检查点保存在 ~/.ReinAgent/checkpoints/<taskId>/，仅供本机会话回退使用。
