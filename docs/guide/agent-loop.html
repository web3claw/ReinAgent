Agent 运行回路

一次运行的六个阶段与事件出口

一次 Agent 运行从用户消息开始，到工具结果回灌模型、直至回合结束。以下是回路中的关键阶段。

阶段动作
装配assembleTurnContext 组装系统提示词、工具定义与上下文结构
推理按当前推理强度与步数上限调用模型
派发模型返回工具调用，经审批门（beforeToolCall）判定
执行执行工具并收集结果，受尺寸闸门约束
回灌工具结果写回上下文，触发下一轮或结束回合
落盘会话、检查点与用量记录写入本地
请求预览与真实发送共享同源装配逻辑，发送前即可完整查看系统提示词、工具定义、上下文结构与原始请求 JSON。
