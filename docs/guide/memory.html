本地长期记忆

作用域隔离、自动沉淀与审查合并

本地长期记忆让 Agent 随着使用逐步熟悉你的偏好与技术栈，且数据 100% 留在本机。

自动经验沉淀

会话交互过程中自动提取用户的个人偏好、编码规范与技术栈习惯并持久化落盘。

分层作用域隔离

作用域用途
全局记忆（Global Memory）跨项目通用的习惯与偏好，在所有项目中生效
项目级独立记忆（Project Memory）特定项目的专有业务逻辑，避免污染其他项目

审查与防遗忘

具备记忆审查、合并组织与冲突解决机制：低价值记忆会被衰减，重复记忆会被合并，冲突记忆会被重新裁决，避免长期使用后记忆库退化。
