Git 工作台

分支、行级差异与 AI 提交信息

Git 工作台把仓库操作收敛到工作台顶栏与预览面板，不需要切到终端。

分支与提交

能力说明
分支检出与新建顶栏快速切换当前分支、按需新建分支
行级差异未暂存 / 已暂存改动逐行对比
AI 提交信息CommitDialog 根据实际改动生成提交信息
仓库初始化空目录一键初始化 Git 仓库

PR / MR 面板

Git 面板底部的 PR 区块把托管平台的评审闭环搬进工作台：按远端地址自动选择 gh（GitHub）/ glab（GitLab），不依赖任何网页跳转。

能力说明
状态总览当前分支 PR 编号 / 标题 / 状态 / 草稿标记、+N −N 变更量、门禁（可合并 / 有冲突 / 被阻塞 / 落后 / 检查未全绿）与审查结论徽标
CI 检查逐项列出检查名称与状态（通过 / 失败 / 进行中分色），点击直达运行日志
动作五连转正式 / 转草稿 / 合并（合并提交 · Squash · Rebase，可勾选删除分支）/ 关闭 / 重开；门禁未通过或要求修改时合并按钮禁用并说明原因
创建 PR标题 / 描述 / 目标分支（默认自动解析 origin/HEAD → main → master）/ 草稿勾选；描述经 stdin 传递，规避 shell 转义问题
交给 Agent 修一键聚合待处理反馈（失败与进行中的 CI、行内审查意见、失败日志摘录）组装成结构化指令预填进输入框，你确认后再发送
CLI 未安装 / 未登录 / 远端非 GitHub·GitLab 时如实提示安装命令与错误原文，不做静默降级。

与 Agent 协同

Agent 在仓库内工作时，所有文件改动都会经过检查点留存，可逐轮回退；Git 面板同步展示当前改动，提交前你能看到 Agent 究竟改了什么。
