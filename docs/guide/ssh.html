SSH 项目

连接远程机器：文件工具/命令/Git 查看全程作用在远端

ReinAgent 可以把远程机器上的目录当作工作区：Agent 的文件工具、命令执行与 Git 查看全部作用在远端。适用于管理云服务器项目、操作无法本地 clone 的环境、与手机远控协同运维。

连接方式

项说明
工作区形态ssh://[user@]host[:port]/path——任务 / 看板卡片 / 定时任务的工作区直接填该地址，零迁移获得远程能力
新建入口侧栏「项目 ▸ +」→「SSH 连接…」：主机 / 端口 / 用户 / 远端路径 / 密码（可选）/ 私钥路径（可选），支持「测试连接」与从 ~/.ssh/config 导入
认证密钥 / agent / 密码三态：Key 与 Agent 走系统 ssh 默认生态（BatchMode）；密码经 SSH_ASKPASS 注入（仅 Linux / macOS，Windows 如实提示），保存于本地 0600 认证文件
代理沿用应用出网代理设置（HTTP CONNECT），链路 keepalive 5s×3 自检——半死连接 15 秒内判定并给出可读错误

远端能力

能力说明
Agent 文件工具列目录 / 读取 / 写入 / 编辑 / 删除 / glob / grep 全部经 shell 模拟文件 API 作用于远端（ls/cat/mkdir+cat/test 守卫/find/grep -rnE），相对路径 .. 逃逸一律拒绝
命令执行远端任意 shell 命令（以项目根为工作目录），60s 超时防挂死
终端面板PTY 直接承接 ssh -t 交互式远端 shell，登录后自动落在项目根
Git 查看（只读）status / log / diff / branch 等只读子命令在远端执行；写操作如实拒绝并提示
看板 / 定时任务卡片与定时任务可绑定 SSH 工作区，无人值守操作远端
v1 边界（如实提示不静默）：SSH 工作区不支持检查点回退、worktree、PR 面板、Wiki 与知识库索引；命令直接改动远端文件，无本地前像可回退，请谨慎执行写操作。
