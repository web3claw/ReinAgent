模型与协议

四协议接入、元数据解析与统一代理

ReinAgent 严格遵循「零猜测」铁律：不写死任何模型上下文大小、Token 上限或是否支持多模态，而是完整解析服务端 API 返回的真实元数据。

多协议原生适配

协议端点
Chat Completions/chat/completions
Anthropic Messages/v1/messages
Responses/responses
Google Generative AI/models

Fail-Fast 连通性探测

切换 API 格式即发起真实握手探测；Base URL 会做规范化清洗并自动追加 /v1。网络异常、鉴权失败与解析错误一律完整向用户告警，绝不用假数据掩盖。

真实元数据解析

字段用途
context_window上下文窗口，用于计算真实可用空间
max_output_tokens输出上限
input_modalities输入模态（文本 / 图像等）
若上游接口未返回某个指标，UI 会明确展示为未提供 / 未知并提示用户，绝不臆造。

统一出站代理

在应用中配置 HTTP / SOCKS 代理后，软件内所有出站请求严格走代理：大模型 API 交互、远程模型列表拉取、自更新检查、云端实时语音 STT、Web 抓取、Cloudflare 隧道组件下载。以下地址按白名单自动直连：localhost、127.0.0.1、内部 Ollama 服务等。代理设置会自动同步给 WebView2 / 内置浏览器及终端拉起的子进程环境变量。
