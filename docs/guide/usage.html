用量来源（新增）

每一次模型调用都记录来源，便于判断消耗落在哪里：

来源包含
聊天 / 看板任务 / 定时任务按任务创建来源区分；看板与自动化派发自动打标
子代理Agent 工具派生的子代理轮次单独记账
笔记 AI / 提示词增强 / 提交信息三条轻量 one-shot 调用链
记忆整理 / 图谱抽取 / 标题生成后台与辅助调用
知识库向量embedding 请求按 prompt token 记账

来源 × 模型 与 7×24 周热力图

每个来源内部的模型构成以堆叠条展示；另有一周 × 24 小时热力图，直观看出使用的时间分布。

口径：total = 输入 + 输出（缓存读写为独立分项，不重复累加）；缓存命中率 = 缓存读 /（输入 + 缓存读）。响应未返回 usage 的调用不记账，绝不编造数值。
