场景默认模型

按场景分配模型：聊天 / 向量 / 记忆 / 笔记 / 图谱

不同任务对模型的要求并不相同：聊天要长上下文与强推理，标题生成、提交信息只要快速便宜，知识库向量与图谱抽取又各需专门能力。场景默认模型让每个场景各用其长。

五个场景

场景覆盖范围存储位置
聊天（默认）会话主链路、上下文压缩、任务标题等所有未单独指定模型的调用settings.json 全局默认指针
知识库 EmbeddingRAG 向量化（允许手填模型名，不依赖列表）hubSettings.knowledge
记忆整理记忆抽取与整理批次hubSettings.memory.organizerModel
笔记 AI划词润色 / 翻译 / 续写 / 修复个人 kv 配置
图谱抽取知识图谱实体关系抽取个人 kv 配置

回退与失效提示

场景留空即「跟随聊天默认」，界面直接显示当前实际生效的模型。若绑定的服务商或模型被删除 / 停用，会自动回退到聊天默认，并在该行以警示色标出具体失效原因（服务商不存在 / 已停用 / 模型不存在 / 已停用），绝不静默把请求发往不存在的模型。

场景默认模型读写的是各场景原有的配置项（零迁移），因此与知识库页、记忆页等处的设置始终是同一份数据，任一处修改另一处即时一致。
