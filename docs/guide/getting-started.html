快速开始

三种运行方式、首次配置与数据落点

三种运行方式

ReinAgent 面向普通用户提供免安装的绿色单文件，面向开发者提供源码运行。三种方式共用同一份本地数据底座与配置目录。

方式命令 / 入口前置条件
桌面绿色版前往 Releases 下载对应系统的可执行文件（Linux AppImage / 二进制、Windows 便携 .exe、macOS 应用）无需 Node.js / Python / Rust，解压或双击即跑
源码运行bun install 后执行 bun run tauri dev需要 Bun ≥ 1.1、Node.js ≥ 20、Rust stable
正式打包bun run tauri build产物输出至 src-tauri/target/release/bundle/

源码运行

# 依赖安装（务必使用 Bun，仓库以 bun.lock 锁定版本）
bun install

# 开发模式：前端开发服务器 + Tauri 桌面窗口
bun run tauri dev
项目使用 Bun（bun@1.4.2 与 bun.lock）作为唯一包管理器。严禁使用 npm / pnpm 更改锁定文件。

首次配置

启动后在设置中完成两件事即可开始工作：

配置项说明关键字段
模型供应商预设 DeepSeek、OpenAI、Anthropic Claude、Google Gemini、Ollama、SiliconFlow 等，也可自由添加自定义兼容端点服务商、API 格式、Base URL、API Key
工作区项目指定本地目录或 SSH 远程仓库作为 Agent 的工作范围项目路径
API Key 保存在本地文件 ~/.ReinAgent/provider_config.json，不上传任何三方服务器。
