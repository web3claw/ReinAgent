知识库与笔记系统

纯净 Markdown 物理映射、Milkdown 所见即所得编辑、AI 助手与对话整理笔记

本地优先、纯净双栏的知识库架构

ReinAgent 提供了完全本地自治的笔记本与 Markdown 知识库系统，位于左侧常驻导航栏「笔记」（BookOpen 图标）。所有笔记与目录均真实映射到本地文件系统，拒绝私有格式绑架。

核心特性概览

特性实现与细节
物理文件落盘数据持久化于 ~/.ReinAgent/notebooks/，每个笔记本对应真实物理文件夹，每篇笔记对应独立 .md 文件，与 Obsidian / Typora 等外部工具 100% 互通
多层目录层级支持无限级嵌套子文件夹与即时搜索过滤；支持笔记本悬停重命名、新建子文件夹、新建笔记与安全删除
所见即所得编辑器基于 Milkdown / ProseMirror 与 Nord 优雅主题，无缝打字、支持块级与行级格式即时渲染
三态视图切换顶部滑动胶囊无缝切换 预览 (Eye) / 编辑 (Edit) / 分栏 (Split) 三态，兼顾沉浸阅读与精细源码调整
快捷格式工具栏常驻快捷语法按键：H2、H3、粗体、斜体、删除线、行内代码、引用块、无序/有序列表、任务待办、分割线、代码块
AI 写作助手侧弹窗右上角 Sparkles 唤出抽屉弹窗（覆盖式设计，保持编辑区稳定不抖动），支持全文重构、段落润色、代码解释、要点总结与自定义提示词
任务对话一键整理笔记在任务对话中点击顶栏 [📄 整理笔记 ⌄]，AI 自动提炼对话脉络与技术结论并沉淀为 Markdown 笔记，支持一键跳转查看

物理路径与存储规范

层级物理位置与机制
根目录~/.ReinAgent/notebooks/
默认笔记本~/.ReinAgent/notebooks/default/（首次启动自动创建，中文展示为“默认笔记本”）
笔记文件~/.ReinAgent/notebooks/<notebook>/<subfolder>/<title>.md
文件安全与防抖编辑器内置防抖自动落盘机制，同时严格对标系统安全边界，防止跨目录路径穿越
笔记本数据绝不经过任何中心化云服务，所有读写均由 Rust 后端 notes_fs.rs 原生接管，并带 Web Mock 兼容层保障无头环境调试。

知识图谱

笔记与世界知识可以沉淀为实体—关系网络，既能可视化浏览，也能反向增强语义检索。

能力说明
抽取知识库设置页对任意笔记「提取图谱」（支持批量），单轮模型按封闭枚举输出实体与关系
实体与关系模型实体 5 类：概念 / 人物 / 组织 / 技术 / 项目；关系 5 类：属于 / 相关 / 依赖 / 包含 / 对比。同名实体全局去重（不区分大小写），同实体对同类型关系只保留一条
可视化侧栏「知识图谱」页：Canvas 力导向图，节点按类型分色、半径随关系数量增长；支持拖拽节点、滚轮缩放、点击查看详情、按名称搜索与类型筛选
人工校正可删除实体 / 关系，也可把重复实体合并（关系自动改挂、自环与重复自动清理）
检索增强语义检索命中笔记后，按 1 跳关系扩展出相邻实体关联的其他笔记一并返回（附「图谱」标记，排在语义命中之后）
图谱模型可在「设置 ▸ 通用 ▸ 场景默认模型 ▸ 图谱抽取」单独指定，未配置时跟随聊天默认模型；抽取用量计入「用量统计 ▸ 用量来源」。
